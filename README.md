# Geometry Rush

A small neon runner prototype built as a simple HTML5 canvas game.

## Structure

- `index.html` – page shell
- `css/game.css` – styling and UI layout
- `js/main.js` – game loop and orchestration
- `js/player.js` – player physics and state
- `js/levels.js` – level definitions
- `js/collision.js` – collision helpers
- `js/audio.js` – lightweight synth sound effects

## Run locally

Open `index.html` directly in a browser, or serve the folder with a simple local web server:

```bash
cd geometry-rush
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Controls

- Space / W / Up Arrow to jump
- Mouse click or tap also triggers jump
